my-wa-bot 隱私權政策

最後更新：2026-11-08

my-wa-bot 是一個個人測試用的 WhatsApp 聊天機器人，透過 Meta 的 WhatsApp Cloud API 自動回覆訊息。

收集的資料

當你傳訊息給本機器人時，Meta 會把以下資料轉給我們：你的 WhatsApp 電話號碼、WhatsApp 顯示名稱、訊息內容與訊息編號。

資料用途

這些資料只用來產生並送出自動回覆，不會用於廣告、分析或其他用途，也不會出售或提供給第三方。

資料保存

我們不會把訊息內容或電話號碼存進資料庫。程式只會在記憶體中暫存訊息編號以避免重複回覆，程式重新啟動後即清除。

Meta 的處理

訊息經由 Meta 平台傳遞，Meta 對資料的處理適用 WhatsApp 隱私權政策。

刪除資料與聯絡方式

如有任何問題或刪除請求，請寄信至 lyenliang@gmail.com。

Privacy Policy (English)

my-wa-bot is a personal test WhatsApp chatbot using Meta's WhatsApp Cloud API. When you message it, we receive your WhatsApp phone number, profile name, message content and message ID. This data is used only to send an automated reply. It is not stored in any database, sold, or shared with third parties; message IDs are kept in memory only to avoid duplicate replies and are cleared on restart. Messages are delivered through Meta, whose handling is governed by the WhatsApp Privacy Policy. For questions or deletion requests, contact lyenliang@gmail.com.
